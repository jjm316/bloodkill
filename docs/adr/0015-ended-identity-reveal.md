# 终局公开全员真实身份

终局弹窗需要按真实家族分组，显示每个人的昵称、身份牌等级及胜负。原投影在结束后仍隐藏他人身份，公开亮牌也不足以确定真实家族：小丑和审判者的徽记可以与真实所属不符。

产品方确认采用阵营对照布局及全员结算（2026-10-11）。在 ended 状态的公共 players 条目中增加 identity，向玩家、旁观者和回放终局公开真实 faction 与 rank；setup 和 active 状态不包含此字段。进行中的隐藏身份边界保持原有约定。

## Considered Options

- 从亮牌颜色或本地备忘标记推断：无法表达真实身份，否决。
- 在整个回放或进行中公开身份：泄露尚未结束对局的隐藏信息，否决。
- 只在终局状态投影公开身份（采纳）：刷新、重连和回放末帧都能获得完整结算；回放此前各帧保持保密。

## Consequences

- 这是投影的新增字段，不修改规则胜负、事件事实或存档格式。
- 个人胜负使用引擎 ranking.score，而非捕获状态或 ranking.place；place 不是身份牌等级。
- 两家族分组使用现有红、蓝颜色，审判者紫色且独立分组；偶数局省略审判者分组。
- 旧客户端可忽略新增字段；旧投影缺失身份时界面明确显示身份未记录，不推测所属。
- 终局自动弹出，可关闭和再次查看；宽屏两家族并排、审判者下方独立，手机纵向排列，长名单滚动时关闭入口保持可达。
