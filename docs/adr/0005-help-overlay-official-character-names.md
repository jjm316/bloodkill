# 帮助浮层使用官方角色名，对局实时显示维持等级数字

本项目是 Blood Bound 兼容实现，此前遵循规则语料的"界面只用原创显示文案"提示，等级在 UI 中一律显示"等级N"、角色名不进任何界面文案。教学/图例功能立项时裁决反转：新手拿官方名才能对照原版资料与朋友的口语称呼，自创一套名字只会制造第三套词汇。决定：官方角色名（1 长老 / 2 刺客 / 3 小丑 / 4 炼金术师 / 5 感应者 / 6 守护者 / 7 狂战士 / 8 法师 / 9 交际花）仅出现在帮助浮层的静态规则文案中；对局实时显示（亮牌槽、技能横幅、事件日志）维持纯"等级N"不变——原裁决对实时显示的关切（名字是多余的一层映射、挤小屏空间）依然成立。边界前提：私人朋友圈部署，不对外分发。

## Considered Options

- **自创原创角色名**：规避 IP 暴露最彻底，被否决——私用部署收益为零，且与语料、朋友口语形成三套词汇。
- **全 UI 带角色名**（日志"发动了小丑技能"、亮牌槽加名字）：被否决——实时显示里名字不承载额外信息，推翻 issue 23 裁决的理由仍然有效。
