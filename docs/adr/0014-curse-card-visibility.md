# 诅咒卡归属公开、真假仅审判者可见

首个实现把诅咒卡当成完全私密信息：CurseDistributed 事件全禁播（连审判者本人客户端都收不到）、curse_assignments 不进任何视角投影、GameEnded 载荷不带归属、回放走旁观投影同样看不到。这带来三个缺口：审判者刷新/重连后忘记自己把真/假发给了谁（实体桌游中他显然记得）；语料终局验收动作「公开诅咒卡」没有对应实现；座位卡上看不到谁持有诅咒卡。产品方裁定（2026-10-11）：两张诅咒卡的**归属（谁持有）对全员公开**；**真/假之分仅审判者可见**，且经服务端投影下发、断线重连不丢；**终局全员翻开真/假归属后再判定胜负**。策略影响（家族知道哪两人持咒后可针对性避开领袖安排）已知并接受，采实体桌游「当面发牌谁都看得到谁拿了牌」的读法。

## Considered Options

- **维持全员完全不可见（含终局与回放）**：被否决——审判者记忆丢失无法自愈；终局揭晓是语料已锚定的动作，属实现缺口而非规则本意。
- **归属与真假对全员公开**：被否决——真假公开即摧毁审判者的核心欺骗资产，暗置语义作废。
- **持有者本人额外知道自己的卡（或其真假）**：被否决——超出「暗置」语义，信息结构变化无必要。
- **归属公开 + 真假仅审判者可见（采纳）**：与实体发牌行为一致；真假知识只回到做出选择的审判者手里，不给任何第三方新增信息。

## Consequences

- 部分取代 ADR 0003 的「真/假诅咒归属的私密事件过滤与投影保密维持不变」条款（0003 的时机裁决不受影响）。
- CurseDistributed 事件转为公开，载荷只含 recipientPlayerId（去掉 curseId，真假不得进任何公开事件流）；PRIVATE_EVENT_TYPES 收缩为 CurseViewed（保留字）。真假的权威记录仍在引擎状态与服务端存档的命令载荷（choose-skill assignments）中。
- 投影：公开 players[] 增持卡字段；审判者 viewer 块增 curseAssignments 私字段（投影驱动，重连安全）；GameEnded 载荷增 curseAssignments（终局全员翻开）。
- 规则版本 0.6 → 0.7 硬切（同 0.2→0.3、0.3→0.4 先例），进行中旧存档不兼容；golden 按新事件与投影形状重生成；PROTOCOL.md 同步。
- 家族策略层面新增「知道哪两人持咒」的公开信息（产品方已接受）。
