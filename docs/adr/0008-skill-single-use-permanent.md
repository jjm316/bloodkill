# 技能一律一次：已使用或已弃用永不再开窗

来源 C 规则文本写"（炼金治疗）若退回 rank，之后重新展示 rank 时可再次使用能力"（rank 4 行与 `skill.reveal-rank` 待验收重点两处），2026-08-22 澄清另有一条"decline = 永久失去技能"注记——两条合起来需要调和成一条总则。旧引擎 `skills_used` 只增不减，实际行为是一律一次，与规则书前一处相反且无 ADR 记录。产品方裁定（2026-10-03 规则共识访谈，**推翻来源 C 原文**）：**技能已使用或已弃用后永不再开窗**；炼金治疗退回 rank、之后重新亮出 rank 也不能再次发动。炼金（rank 4）技能效果只有治疗（退 token）与 1 点伤害，不附带任何"技能复活"。

## Considered Options

- **对齐语料（已弃用不可恢复、已使用可经退 rank 恢复）**：两条注记字面都成立；被否决——产品方不接受"炼金让同一个人技能放两次"，收窄炼金为纯治疗/伤害。
- **一律可恢复（decline 也可洗回）**：直接推翻 2026-08-22 注记且催生"弃用—退 rank—重亮"的洗技能循环，被否决。

## Consequences

- 引擎现行为（`skills_used` 永不清除）已符合本裁决，**无代码改动**；语料两处原文改写，以本 ADR 为追认记录。
- 与 ADR 0009 方案 A 协同：已用、已弃用、被封印共用同一把永不清除的资格锁，状态上不做区分（审计翻事件历史）。
- 玩家侧表述统一为"技能只有一次"；帮助文案同步。
