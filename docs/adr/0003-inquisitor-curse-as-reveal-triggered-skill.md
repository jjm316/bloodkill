# 诅咒分发改为审判者亮等级触发的技能窗口

官方规则书与规则语料都没有锚定审判者分发诅咒的时机（能力原文只写 "when the Inquisitor uses his ability"），首个实现因此把它做成对局中全程常驻的供应区动作：只要诅咒未分发，"秘密将诅咒牌交给"的面板从开局一直挂在审判者的动作区。产品方裁定（2026-09-05）：诅咒分发就是审判者的技能，与其他 rank 1–9 角色技能同一套实现——因攻击或挡刀伤害亮出等级（fleur-cross）时开启唯一一次技能窗口，在窗口中选择发动（真/假诅咒暗置分给不同玩家）或放弃；放弃或从未亮出等级，诅咒永远留在供应区、诅咒胜路作废。此裁决推翻引擎内"fleur-cross 是设置阶段能力、永不触发技能窗口"的旧设定。

## Considered Options

- **保持全程可发、仅加显式发动步骤**：被否决——审判者可以憋到残局、等胜方领袖几乎确定时再把真诅咒塞给他，几乎稳赢，是退化策略。
- **开局设置窗口（任何匕首行动前发完）**：最贴实体游戏的设置阶段习惯，被否决——开局匕首持有者不是审判者时，窗口可能在他来不及操作前就关闭，诅咒变成无法分发的死牌。

## Consequences

- 规则版本 0.3 → 0.4 硬切（同 0.2→0.3 先例），进行中的旧存档不兼容，相关对局需重建。
- 常驻分发命令移除，分发改由技能命令承载；真/假诅咒归属的私密事件过滤与投影保密维持不变。
- 面向玩家文案统一为「技能／发动能力：分发诅咒牌」；词表（CONTEXT.md）已按"分发经由技能窗口"更新（诅咒卡、真诅咒、假诅咒、技能窗口条目）。
