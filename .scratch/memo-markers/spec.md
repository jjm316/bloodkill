# 玩家备忘标记（玩家框右上角的私有备忘角标）

Type: task
Status: resolved（2026-09-05 实现，commit 6c5ce08；收尾记录见本文件末尾 Comments）
ADR: docs/adr/0004-memo-markers-client-only.md
裁决日期: 2026-09-05（产品方 grilling 裁决，CONTEXT.md 已增"备忘标记"词条）

## Problem Statement

（从玩家视角描述）对局中玩家对其他人阵营与等级的推理只能靠脑子记：唯一可看的公开信息是三格线索槽（公开亮牌事实）和自己开局看到的右邻徽记，一旦推出"这家可能是玫瑰""他大概是等级 5"，没有任何地方可以记下来，聊天一打断、切个页面就忘，手机上尤其难受。

## Solution

每张玩家框右上角常驻一个**备忘角标**（玩家的私有备忘标记，仅存在于自己的设备上）：点击弹出轻量选择器，可选颜色（玫瑰红 / 野兽蓝 / 灰？）与数字 1–9 或"审"；角标同时显示颜色与数字，一眼扫全桌即可回忆全部推理。开局时自动把"我看到徽记的那位玩家"（右邻）的角标填上所看徽记的颜色，之后可自由修改。备忘保存在本机 localStorage（按房间码 + 对局维度），刷新、断线重连不丢，新对局开始自动清空。纯前端功能，服务端与协议零改动，其他玩家永远看不到。

## User Stories

1. As a 玩家, I want 每张玩家框右上角常驻一个备忘角标空位, so that 我知道可以在这里为该玩家记笔记。
2. As a 玩家, I want 无标记时角标显示为极淡的空心占位, so that 桌面不显得杂乱，但仍能看出此处可点。
3. As a 玩家, I want 点击角标弹出轻量选择器并选颜色（玫瑰红/野兽蓝/灰？）, so that 我能记下对某人阵营的猜测。
4. As a 玩家, I want 选择器里可选数字 1–9 或"审", so that 我能记下对某人等级或审判者身份的猜测。
5. As a 玩家, I want "审"与数字互斥（同一角标二选一）, so that 角标语义唯一，不会出现自相矛盾的记录。
6. As a 玩家, I want 角标同时显示颜色底和数字/"审", so that 扫一眼全桌就能回忆起所有推理。
7. As a 玩家, I want 只选颜色不选数字时角标也成立（徽章中心留空）, so that 我可以只记阵营倾向。
8. As a 玩家, I want 未主动选玫/兽时颜色默认为灰（？）, so that 灰色天然表达"未知/审判者候选"，不需要额外操作。
9. As a 玩家, I want 开局自动把我看到徽记的玩家（右邻）的角标填成该徽记的颜色, so that 开局信息不用手动誊抄。
10. As a 玩家, I want 自动填充只填颜色、不动数字, so that 数字始终代表我自己的推理。
11. As a 玩家, I want 我手动修改或清空过的角标在本局内不再被自动重填, so that 我的主动判断不会被系统覆盖。
12. As a 玩家, I want 备忘保存在本机并按房间+对局区分, so that 刷新页面、断线重连后笔记还在。
13. As a 玩家, I want 检测到新对局（对局标识变化）时备忘自动清空, so that 上一局的推理不会误导新的一局。
14. As a 玩家, I want 选择器内注明"仅保存在本设备", so that 我不会误以为手机和电脑的备忘会同步。
15. As a 玩家, I want 其他玩家永远看不到我的备忘角标, so that 我的推理完全私密（备忘根本不上传）。
16. As a 观众, I want 也能使用备忘角标, so that 观战时同样可以做笔记（从空白开始，无自动填充）。
17. As a 玩家, I want 备忘角标与三格线索槽在视觉上明显不同, so that 不会把我的私有猜测误读成公开亮牌事实。
18. As a 玩家, I want "清除"一键清空某玩家的全部备忘, so that 推理被推翻时能干净重置。
19. As a 玩家, I want 自己的座位框不显示备忘角标, so that 不浪费空间（自己的身份自己已知）。
20. As a 玩家, I want 回放页不显示备忘角标, so that 复盘视图保持客观公开。
21. As a 手机玩家, I want 角标与选择器在窄屏下足够大、点按不误触相邻元素, so that 手机上好用。
22. As a 玩家, I want 备忘完全不进命令与协议, so that 服务端、存档、规则版本完全不受影响。

## Implementation Decisions

- **纯客户端状态（ADR 0004）**：备忘标记只存玩家设备 localStorage（沿用 `bloodbound:*` key 先例），key 按房间码 + gameId 维度；不进 WebSocket 协议、引擎、投影或事件；任何命令 payload 不得携带备忘数据。检测到 gameId 变化即清空全部备忘。
- **数据形状**：每目标玩家一条 `{ color: 'rose' | 'beast' | 'gray', mark: 1–9 | '审' | 无 }`；角标一旦有内容，颜色恒为三选一，灰为兜底默认（裁决 Q8）；"审"与数字互斥。
- **自动填充规则（裁决 Q9）**：仅当目标角标完全未被动过且 `seenNeighbourClue` 指向该玩家时，填入所看徽记颜色（rose→玫、beast→兽）；只填色不填数；玩家手动编辑或清空后，该玩家本局不再自动填充。观众无 viewer（拿不到 `seenNeighbourClue`），一律从空白开始。
- **视觉**：Seat 座位卡新增右上角绝对定位角标容器（现无角标位）；空态=极淡空心；有内容=色底徽章+中心数字/"审"。颜色沿用三格线索槽的既有色语言（玫红/兽蓝/灰），但徽章造型与槽位明显不同，保持"私有猜测 vs 公开事实"的视觉区分。
- **范围**：自己的座位卡不渲染角标；观众可用；回放屏（复用 Board）不渲染；不做备忘与公开亮牌的冲突提醒；等待室无桌面不涉及；对局结束（ended）角标仍显示。
- **界面文案**：面向玩家一律用"备忘/备忘标记"，不单说"标记"（与身份标记 token 划清界限，见 CONTEXT.md 词条 _Avoid_ 行）；全部简体中文。

## Testing Decisions

- **单一测试缝隙**：真实房间 + 浏览器渲染层（最高缝隙）。用测试工具箱起服务端与测试房，浏览器实测交互与视觉，并覆盖手机宽度视口；`npm run build` 保证编译通过。
- 只验证玩家可见行为（角标出现/自动填充/手动编辑粘性/持久化/换局清空/观众与回放行为），不测组件内部实现。
- 服务端零改动，后端测试套件不动；不引入前端单测基建（`.scratch/frontend-test-infra` 另行推进）。
- Prior art：既有 e2e 脚本驱动真实对局验证房间流程（`.scratch/e2e-curse.py`）；本功能在其流程之上补浏览器 UI 实测步骤。

## Out of Scope

- 备忘的多端同步、云存储或服务端存储（ADR 0004 明确否决）。
- 备忘与公开亮牌事实的冲突提醒。
- 自定义颜色、自由文字备注。
- 前端单测基建（另立 effort）。
- 协议、规则版本、存档格式的任何变更。

## Further Notes

- 徽记不是阵营事实（rank 3 徽记恒为敌对家族、审判者徽记随机），自动填充的初始颜色只是"所见"，不是真相——词表已明确备忘标记始终是猜测，与公开亮牌矛盾时无需一致。
