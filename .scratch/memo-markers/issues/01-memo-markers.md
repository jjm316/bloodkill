## 范围

spec 的全部实现决策一次落地，不留中间态（纯前端纵切，服务端/协议/存档零改动）：

- 备忘状态与持久化：每目标玩家 `{ color: 'rose'|'beast'|'gray', mark: 1–9|'审'|无 }`；按房间码 + gameId 存 localStorage（沿用 `bloodbound:*` key 先例），gameId 变化自动清空；任何命令 payload 不携带备忘数据。
- 座位卡角标：右上角新增绝对定位角标容器；空态=极淡空心可点击；实态=色底徽章+中心数字/"审"；颜色复用三格线索槽色语言（玫红/兽蓝/灰），徽章造型与槽位明显不同；自己的座位卡不渲染角标。
- 选择器：点角标弹出轻量面板——3 色块（灰默认预选）、1–9 数字格、"审"、清除按钮、"仅保存在本设备"说明；点选即生效，点外部关闭；"审"与数字互斥。
- 自动填充（Q9 裁决）：`seenNeighbourClue` 指向的玩家角标初始填其徽记颜色（rose→玫、beast→兽），仅当该角标完全未被动过；手动编辑或清空后本局不再重填；只填色不填数；观众无 viewer，一律从空白开始。
- 范围条件：观众可用；回放屏（复用 Board）不渲染；不做与公开亮牌的冲突提醒；对局结束角标仍显示。

## 工作顺序

1. 备忘状态 hook：数据形状、localStorage 读写（房间码+gameId 键）、gameId 变化清空、"动过"标记（支撑自动填充粘性）。
2. Seat 角标渲染：空态/实态视觉、范围条件（自己无、回放无）。
3. 选择器交互：色块/数字/"审"/清除、灰默认、互斥、点外部关闭、"仅保存在本设备"文案。
4. 自动填充接入 seenNeighbourClue。
5. `npm run build`；测试工具箱起真实房间，浏览器逐项过验收（含手机宽度视口）。

## 验收

- 角标空态/实态视觉符合 spec，与三格线索槽造型明显不同；自己的座位卡无角标。
- 选择器完整：灰默认预选、"审"与数字互斥、清除、点外部关闭、"仅保存在本设备"说明。
- 自动填充按 Q9：只填色、只填未动过的角标、手动编辑后粘住。
- 刷新/断线重连后备忘保留；gameId 变化自动清空。
- 观众可用（从空白开始）；回放页无角标；全程无任何 WebSocket 备忘流量。
- `npm run build` 通过；真实房间浏览器实测通过，含手机宽度视口。
- 文案全部简体中文，不单说"标记"（避免与身份标记混淆）。
