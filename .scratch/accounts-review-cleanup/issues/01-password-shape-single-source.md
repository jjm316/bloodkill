## 要交付的行为

玩家与运维管理员在任何入口设定密码时，「6–12 个字符」的判定与中文提示完全一致：注册/改密走原有校验器；管理 HTTP 重置接口对非法密码返回账号校验器自身的错误码与中文消息；管理 CLI 交互提示复用同一校验器，规则说明与服务端判定不再漂移。管理重置接口的错误码对齐（由管理面通用码改为密码校验码）是 spec 决策 2 明确豁免的唯一行为变更。
