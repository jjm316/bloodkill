# 02：房间连接终止管线收敛为谓词助手

Type: task
Status: resolved
Blocked by: None（可立即开始）

## 要交付的行为

服务端「按条件停掉一批已建立连接（发中文原因帧后关闭）」的逻辑从五处手写拷贝收敛为一个谓词驱动的终止助手：退出登录、修改密码停其他设备、管理重置停全部连接、旁观转玩家停旁观连接、管理关房停全房连接，五条路径全部改走助手；「按连接对象从注册表移除」的扫描只剩一份，退座确认路径复用该最小部分。对玩家完全不可见：五条路径的错误码、中文文案、排除参数（如改密不停当前设备）语义逐一保持不变。

无。

## 验收条件

- [x] 「过滤连接注册表 → 逐条发指定中文原因帧 → 关闭」的循环形状在服务端只剩助手一处；五条路径均调用助手，无残留手写拷贝。
- [x] 助手返回终止的连接数，管理重置停连路径的返回值语义（用于回复中的停止数）不变。
- [x] 退座路径不被并入助手（它发确认帧），但不再自带注册表移除扫描。
- [x] 既有测试锁定的五条路径终止行为全部保持：退出登录只停当前登录的连接、改密只停被撤销登录的连接、管理重置停该账号全部连接并计数、转玩家停旁观连接但排除自身、关房停全房连接——错误码与中文文案逐一不变。
- [x] `python scripts/check.py` 通过。
