## 要交付的行为

管理者在服务器终端查看账号占用、房间状态、房主和在线玩家，获得后续重置及清理的明确目标。

## 前置依赖

[10 按账号加入房间及跨设备恢复座位](10-join-and-resume-account-seat.md)

## 验收条件

- [ ] CLI 随部署包运行，通过正在运行的服务读取数据，支持必要端口/数据配置。
- [ ] 只有服务器本机独立管理凭证可访问，账号或房主身份不取得管理权限。
- [ ] 中文输出可用于确认目标，不含密码摘要、会话或管理凭证；故障有非成功结果。

## 测试与验证

- [ ] **V13.01｜真实 CLI/临时服务**：创建两个账号和多个状态房间，通过实际进程调用查看命令，对照显示的房号、房主、占用和在线情况。
- [ ] **V13.02｜权限反例**：无凭证、错误凭证、普通账号、房主及非本机来源分别被拒，伪造转发来源信息不能放开权限。
- [ ] **V13.03｜配置/故障**：默认与非默认端口/数据目录、服务未运行、配置不匹配分别有中文反馈和失败退出状态，不能误连另一实例。
- [ ] **V13.04｜输出/副作用**：输出没有任何可用凭证；查看前后房间、账号、事件和计时状态均未被改变。
