# 登录注册入口、账号显示与房间流程

Type: task
Status: ready-for-agent
Blocked by: 01, 02

实施前提：规格已确认；启动须遵循 [spec.md 的实施状态](../spec.md)，当前暂不实施，等待用户后续明确指令。

## 交付

初始页默认登录，清楚切换注册，注册成功自动登录。大厅与房间持续显示当前用户名、改密码及退出入口；大厅能返回当前占用房间，新增房间只有当前账号能够认领。

邀请携带房号、登录后自动进目标；占用冲突、锁房、开局、满员、不存在/已关闭、连接失败均有明确反馈和返回路径。普通等待玩家的退座与房主/对局的返回大厅分别用准确文案表达。

备忘和干涉/日志偏好按账号隔离，停止旧账号私有流和内存状态；延续本设备保存，旧无账号数据不自动迁入。占用时禁用旁观并说明原因；发生接管或会话失效时停止操作、正确展示恢复入口。

## 验收

行为测试覆盖表单、账号持续显示、邀请跨注册/登录切换、等待退座/返回、占用限制、接管/失效与账号偏好隔离。实际浏览器验证桌面和手机无横向溢出、焦点/键盘/回车与自动填充可用、密码显隐和中文提示清楚。
