## 要交付的行为

管理者预览一个等待或进行房间，输入房号确认；备份成功后关闭该房，玩家获通知并能进入新房，其他房间照常运行。

## 前置依赖

[12 一人一个未结束房间及并发占用限制](12-one-active-room-and-races.md)；[19 管理工具在线查看账号和房间](19-admin-inspect-users-and-rooms.md)

## 验收条件

- [ ] 只处理确认的未结束房间，保存可读取备份；取消、目标变化或备份失败不误关闭。
- [ ] 停止该房操作和计时器、通知断开、释放全员占用，输出实际结果和备份位置。
- [ ] 管理关闭不产生胜负、全员身份揭晓或在线回放；没有房主解散按钮。

## 测试与验证

- [ ] **V15.01｜真实 CLI/WS**：分别关闭等待和进行房间，全员连接得到关闭反馈，账号随后可建房或进新房。
- [ ] **V15.02｜对照房间**：同时保留另一进行房间，关闭目标后对照房间仍能合法操作，计时器及占用未改变。
- [ ] **V15.03｜确认/反例**：错误房号确认、取消、目标不存在、已正常结束、预览后状态改变或权限错误，均不关闭目标或相邻房间。
- [ ] **V15.04｜失败注入/备份**：备份目录不可写或写入中断时房间保持可用且占用不释放；成功备份可重放到关闭前事实。
- [ ] **V15.05｜定时器/私有事实**：关闭时存在决策倒计时，推进到原截止后不再生成动作、广播或文件；没有伪造结果或身份揭晓。
