## 交付

新增随部署打包的 server.admin 命令行模块：users、rooms、reset-password 用户名、close-room 房号。通过运行服务处理，使用本机独立管理凭证；普通账号/房主/外网请求不得取得管理权限。CLI 不另起 RoomManager 或直接编辑活动存档。

重置隐藏交互输入新密码及确认，撤销全部登录，不改变房主或座位归属。关闭单房先显示状态并输入房号确认，核验目标未变化、未正常结束；备份成功后停止操作、取消计时器、通知断开、持久化关闭并释放全员占用，其他房间继续运行。

备份与活动扫描、回放保留清理隔离；不得伪造正常终局/胜负。失败或重复操作明确报错，重启不恢复已关闭房间。提供端口/存档目录配置及中文 help，密码不进入命令参数或日志。

## 验收与用法交付

真实 CLI 与临时服务验证查看、重置、撤销在线连接、确认取消、备份失败不关闭、目标变化、已结束/不存在拒绝、清理释放、重启不恢复和其他房间不受影响。

创建并验证 docs/account-admin.md，包含 Windows 本地与 /opt/bloodkill 云端完整步骤、互动输入、备份绝对位置和故障处理。最终向用户给出可复制的真实使用命令及文档链接；不得只宣布工具完成。
