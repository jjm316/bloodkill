# 旧未结束房间停用与回放保留

Type: task
Status: ready-for-agent
Blocked by: 02, 04

实施前提：规格已确认；启动须遵循 [spec.md 的实施状态](../spec.md)，当前暂不实施，等待用户后续明确指令。

## 交付

账号机制首次启用时备份并停用旧等待/进行房间，不按旧姓名创建或认领账号；保留已有正常终局回放，已登录者按房号查看。未结束旧局仅备份，不制作部分回放、不伪造终局或公开隐藏身份。

切换须可重复启动；关闭标记与管理关闭逻辑协调，不能重启后恢复旧占用，也不能把账号方案的新房间当旧房间再次停用。旧 hostToken 与旧名称协议不再授权，旧客户端提示刷新。部署更新保留账号、会话、关系、管理凭证及备份。

## 验收

使用旧样例存档覆盖等待/进行/已结束三种状态、首次启动、重复启动、切换后新房间、备份可读取和旧已结束回放访问。断言原存档与备份均未伪造胜负或全员身份揭晓，不能绕过新账号校验。
