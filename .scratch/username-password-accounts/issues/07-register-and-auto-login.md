## 要交付的行为

新玩家从注册入口填写用户名和自设密码，成功后自动登录并在大厅看到自己的用户名；重复或非法输入得到可纠正的中文反馈。

## 验收条件

- [x] 用户名唯一、固定且按已确认的字符和大小写规则校验；密码严格为 6–12 个原字符，确认密码必须一致。
- [x] 注册成功建立可持久化的账号及登录身份，并把公开名字显示为注册时的写法。
- [x] 账号凭证不会出现在 URL、响应中的非必要字段或日志；注册失败不留下半个账号。

- [x] **V01.01｜API/边界**：用户名长度 1/2/16/17、中文与英文数字下划线组合、空格及非法字符，逐项断言注册结果和中文提示。
- [x] **V01.02｜API/边界**：密码长度 5/6/12/13、确认不一致、大小写差异及含首尾字符的密码，确认没有截断、去空白或错误归一化。
