## 要交付的行为

管理者确认本人后在终端隐藏输入新密码，重置指定账号；该账号所有设备重新登录，仍可恢复原座位。

## 前置依赖

[14 固定 30 天登录、退出与切换账号](14-fixed-expiry-logout-and-account-switch.md)；[19 管理工具在线查看账号和房间](19-admin-inspect-users-and-rooms.md)

## 验收条件

- [ ] 密码交互隐藏输入与确认，满足 6–12 字符，命令参数和输出不携带密码。
- [ ] 不存在账号、确认不一致或无权限不修改任何账号。
- [ ] 成功撤销全部登录和已有连接，房主/玩家归属保持且重启后仍有效。

## 测试与验证

- [ ] **V14.01｜真实 CLI/会话**：目标账号多个登录及活动连接，经 CLI 重置后全部失效；新密码可登录，旧密码和旧会话不可用。
- [ ] **V14.02｜交互边界**：5/6/12/13 字符、确认不一致、取消输入与未知账号逐项验证退出状态及无副作用。
- [ ] **V14.03｜归属/重启**：目标原房主或进行中玩家重置后仍拥有原房，重启再用新密码恢复；其他账号继续操作。
- [ ] **V14.04｜泄漏/权限**：密码不出现在命令行、标准输出/错误、日志和帮助；普通用户和错误管理凭证不能重置。
- [ ] **V14.05｜失败注入**：持久化或会话撤销失败不返回成功；重新查询或重启后结果与实际状态一致。
