# 账号、登录会话与密码管理

Type: task
Status: ready-for-agent

实施前提：规格已确认；启动须遵循 [spec.md 的实施状态](../spec.md)，当前暂不实施，等待用户后续明确指令。

## 交付

实现开放注册、登录、当前账号、退出及改密码的服务端能力；用户名唯一且固定，按大小写无关规则校验，密码严格为 6–12 个字符。账号与会话在部署保留的数据目录持久化，与游戏清理分离；密码加盐专用哈希，会话不可预测并可撤销。

固定 30 天有效期，刷新和重启恢复；退出撤销当前登录；改密保留当前登录、撤销其他登录；管理重置撤销全部登录。会话失效必须使相关已有 WebSocket 停止操作，不能只限制下一次 HTTP 请求。账号切换、cookie/会话处理与 HTTP/WS 部署要求一致。

## 验收

通过真实请求覆盖中文用户名、大小写重名、并发注册、密码 5/6/12/13 字符边界、错误登录、重启恢复、到期、退出和改密撤销。确认证明无密码/会话泄漏到日志或回放，且已撤销会话不能继续使用旧连接。
