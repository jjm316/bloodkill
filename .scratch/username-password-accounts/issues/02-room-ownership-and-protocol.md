# 账号归属、单房限制与等待阶段退座

Type: task
Status: ready-for-agent
Blocked by: 01

实施前提：规格已确认；启动须遵循 [spec.md 的实施状态](../spec.md)，当前暂不实施，等待用户后续明确指令。

## 交付

创建时绑定房主账号及自身座位；账号持久化关联稳定玩家引用，移除姓名/hostToken 的授权作用。统一校验 API 与 WebSocket，保持锁房和开局后的本人恢复，跨设备新连接接管旧连接。

并发下也保证一个账号一个未结束玩家占用。普通玩家等待阶段主动退座通过可重放命令实现；断线、退出登录、房主返回大厅、对局中离开均保留占用。正常终局释放占用。禁止有占用的账号同时旁观，成为玩家时停止已有旁观连接；回放仍要求登录且只发公开投影。

不增加房主解散、转让、踢人或原房重开。协议升级及错误中文反馈按总规格实现，保持现有规则和私有投影边界。

## 验收

覆盖并发建房/加入、伪造名字/token、锁房/开局本人恢复、新连接接管、等待退座后再加入与存档重放、房主和对局断线保留、正常终局释放、跨设备旁观限制及旧会话撤销。检查旧连接不会重连争抢，玩家退出后座位引用和顺序保持一致。
