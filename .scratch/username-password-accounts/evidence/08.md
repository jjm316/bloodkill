## 实现与公开接口

`POST /api/auth/login` 接收 JSON `{username,password}`，成功 200 `{account:{accountId,username}}`，保留注册时用户名写法。用户名英文大小写不敏感，密码原字符精确匹配。成功创建不可预测的独立会话，经 HttpOnly、SameSite=strict、Path=/、Max-Age=2592000 Cookie 交付，响应 Cache-Control=no-store；会话持久化与注册共用账号数据库，查询不续期。

未知账号、错误/缺失凭证返回中文 401 `auth.invalid-credentials`，非对象/无效 JSON 返回 400 `auth.invalid-input`，跨站 Origin 返回 403 `auth.invalid-origin`，存储失败返回中文 503 `auth.service-unavailable`。失败不设置 Cookie，不替换已有身份。公开 `AccountStore.login(username,password)` 返回 `(Account,token)`，供后续切片复用；当前身份恢复仍使用 `GET /api/auth/session`。

表单默认登录，支持回车、用户名/密码自动填充属性、密码显隐、提交中禁用与同步重复提交防护。登录/注册切换清除密码和确认密码，恢复隐藏状态；失败保留输入并允许纠正重试。
