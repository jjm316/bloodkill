## 行为与公共接口

- `server/admin.py` 新增 `reset-password 用户名` 子命令（`--saves-dir/--port` 与 users/rooms 共用）：先走 19 的防误连核对（`/admin/instance` 安装标识 + 存档目录规范路径，不符即拒绝），**核对通过后才提示输入新密码**。交互隐藏输入：终端走 `getpass`（提示语由 CLI 以 UTF-8 打印，getpass 只取值），stdin 为管道/重定向时逐行读取——不存在回显媒介，安全语义等价（密码不进命令行参数、不回显、不写入输出或日志），测试即以此管道方式驱动真实 CLI 子进程。校验 6–12 个字符且两次一致，中文报错后可重试；直接回车、输入流结束（EOF）或 Ctrl-C 均按取消处理（非零退出，不修改任何账号）。无任何 `--password` 类参数；多余位置参数被 argparse 拒绝。
- `server/admin_api.py` 新增仅回环的 `POST /admin/reset-password`：复用 19 的管理凭证 constant-time 校验（`X-Admin-Token`）、`admin.*` 中文错误与 allowlist 纪律。用户名不存在 → 404「账号…不存在…不会自动创建账号」；非 POST → 405；请求体格式/用户名/密码越界 → 400；持久化或会话撤销失败 → 500「服务暂时不可用，重置未完成」。手写 HTTP 监听扩展为可读 POST 请求体（Content-Length 限制 16 KB、超时约束不变）；密码只经回环请求体传输，不进 URL、日志或任何响应。
- `server/accounts.py` 新增 `AccountStore.reset_password(username, password)`：更新 salt+hash 并把该账号全部未撤销会话置为撤销，**同一 sqlite 事务**提交（任一失败整体回滚）；用户名不存在返回 None（不创建）。返回 (账号, 撤销会话数)。
- `server/app.py` 新增 `_stop_account_connections(account_id)`：撤销提交后停止该账号全部已建立房间 WS，复用 14 的 `_terminate_conn` 终止管线（`auth.session-revoked`「管理员已重置该账号密码，请用新密码重新登录。」→ 关闭），不撤销座位、不改房主归属；返回停止连接数。即使此处遗漏，消息级会话校验与广播惰性踢出兜底。
- 成功输出说明处理的用户名与撤销范围（会话数、停止连接数），并注明归属保留与需新密码重登；`server/README.md` 管理命令小节与 `server/PROTOCOL.md` 错误码表同步（`auth.session-revoked` 涵盖管理重置）。
