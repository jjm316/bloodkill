# 鲜血盟约数字复刻规格

## Objective

构建一个规则行为可验证的浏览器多人联机桌游版本。服务端由用户本地启动，并可通过内网穿透供他人访问；支持目标版本的完整对局、规则解释、存档和回放。首轮开发以桌面浏览器为主，后续完善手机、平板、观战和可选单人 AI。

## MVP boundary

包含：

- 目标版本的完整设置、阶段/回合、玩家行动、冲突结算、能力触发、资源变化和终局计分。
- 6–12 人浏览器多人联机；服务端由用户本地启动并可通过内网穿透访问；固定 seed 调试；事件日志；存档、恢复和逐步回放。偶数局使用两个家族，奇数局加入一名 Secret Order 审判官。
- 浏览器网页客户端（首轮优先桌面）；布局和输入模型需为手机（含 iPhone）及平板保留响应式/触控兼容路径；不做客户端安装包。
- 数据驱动的牌组/单位/地图占位内容；中文界面，文案与素材可替换。
- 规则错误可解释，所有状态由领域引擎裁决。

不包含：

- 未授权的官方插画、Logo、原文卡牌文本、扫描版版图或商业发行包装。
- 首版的在线匹配、账号体系、跨设备同步和高强度 AI；不承诺云端托管，默认由用户自托管服务端并自行配置内网穿透。
- 在版本、扩展和授权未确认前对具体数值或内容做不可逆承诺。

## Acceptance bar

1. 新建 6–12 人对局后，可在无开发者命令的情况下完成一局并看到可解释的胜负解释。
2. 同一初始 seed 与命令序列产生相同事件日志；从日志任意节点恢复后，后续结果一致。
3. 核心规则、终局计分、非法行动、平局、资源不足和同时触发均有自动化场景覆盖。
4. UI 只提交领域命令，不直接变更游戏状态；所有多人对局均由本地运行的服务器/权威引擎再次校验。
5. 用户可在本地启动服务并通过内网穿透让远端浏览器加入；服务升级、回滚以及崩溃或损坏存档都能给出可操作的错误信息。

## Delivery order

先完成 `01 -> 02 -> 03 -> 04`，再并行推进 `05/06/07/10`；`08` 依赖可玩的规则闭环，`09` 依赖回放与 UI，`11` 作为发布闸门。

## 产品决策（已裁定）

- 授权与发布性质：仅个人学习/非商业使用，不对外公开发布。
- 目标出版版本与扩展范围：以用户提供图片对应的出版版本为准，已确认为基础完整版，不扩展到其他扩展内容。
- 官方素材使用：允许使用官方素材（个人学习用途）；素材是否可下载待调研确认。
- 手机/平板支持范围：后续计划支持手机和平板（尽可能全支持），排期靠后，桌面版优先。
- 部署环境：家用机自托管 + 内网穿透；无域名、无 HTTPS 证书。2026-08-29 完成选型调研（见 [research-02](research-02-public-access-tunnel.md)）：默认方案为 cloudflared 快速隧道（免费、免账号、自动 HTTPS/WSS、手机零安装开 URL；本机实测协议全链路通，操作延迟约 1 秒）；想要更流畅再升级 frp + 国内轻量服务器（约百元/年，预期几十毫秒级）。用户裁定明文暴露在个人学习定位下可接受，TLS 由"必须"降级为"建议优先"。
- 语言、引擎、前端与部署模式：Python 标准库 + FastAPI/uvicorn + React/TypeScript/Vite + 单服务器自托管（已定）。
- 审判官局诅咒卡：每名审判者对应 1 张真诅咒和 1 张假诅咒；当前奇数局各有 1 名审判者，因此放置 2 张。

## Open questions

- 官方素材能否找到可下载版本（待调研确认）。
- 内网穿透遗留人工验证项：路由器 WAN IP 是否为真公网（决定端口转发路线是否成立）、trycloudflare 手机侧抽查、frp+VPS 购前实测（见 [research-02](research-02-public-access-tunnel.md) 待验证清单）。
