# 鲜血盟约数字复刻规格

## Objective

构建一个规则行为可验证的浏览器多人联机桌游版本。服务端由用户本地启动，并可通过内网穿透供他人访问；支持目标版本的完整对局、规则解释、存档和回放。首轮开发以桌面浏览器为主，后续完善手机、平板、观战和可选单人 AI。

## MVP boundary

包含：

- 目标版本的完整设置、阶段/回合、玩家行动、冲突结算、能力触发、资源变化和终局计分。
- 6–12 人浏览器多人联机；服务端由用户本地启动并可通过内网穿透访问；固定 seed 调试；事件日志；存档、恢复和逐步回放。偶数局使用两个家族，奇数局加入一名 Secret Order 审判官。
- 浏览器网页客户端（首轮优先桌面）；布局和输入模型需为手机（含 iPhone）及平板保留响应式/触控兼容路径；不做客户端安装包。
- 数据驱动的牌组/单位/地图占位内容；中文界面，文案与素材可替换。
- 规则错误可解释，所有状态由领域引擎裁决。

不包含：

- 未授权的官方插画、Logo、原文卡牌文本、扫描版版图或商业发行包装。
- 首版的在线匹配、账号体系、跨设备同步和高强度 AI；不承诺云端托管，默认由用户自托管服务端并自行配置内网穿透。
- 在版本、扩展和授权未确认前对具体数值或内容做不可逆承诺。

## Acceptance bar

1. 新建 6–12 人对局后，可在无开发者命令的情况下完成一局并看到可解释的胜负解释。
2. 同一初始 seed 与命令序列产生相同事件日志；从日志任意节点恢复后，后续结果一致。
3. 核心规则、终局计分、非法行动、平局、资源不足和同时触发均有自动化场景覆盖。
4. UI 只提交领域命令，不直接变更游戏状态；所有多人对局均由本地运行的服务器/权威引擎再次校验。
5. 用户可在本地启动服务并通过内网穿透让远端浏览器加入；服务升级、回滚以及崩溃或损坏存档都能给出可操作的错误信息。

## Delivery order

先完成 `01 -> 02 -> 03 -> 04`，再并行推进 `05/06/07/10`；`08` 依赖可玩的规则闭环，`09` 依赖回放与 UI，`11` 作为发布闸门。
