# 实现多人联机同步与断线恢复

Type: task
Status: resolved
Blocked by: 05, 07, 08

问题：在事件日志基础上实现由用户本地启动的权威服务端、房间、身份、权限、乐观 UI 回滚、重连、观战和版本不匹配处理；为内网穿透场景定义安全的对外访问配置。

输出：协议草案、房间生命周期、事件确认/重传、断线测试矩阵、最小可观测性指标和滥用边界。

完成条件：网络抖动和重复消息不会产生双重结算；重连后状态 hash 一致；客户端不能绕过服务器提交非法命令；主机离开有明确策略。

## Answer

- 为 WebSocket 命令加入稳定 `commandId`、`expectedRevision` 与 `ack`；重复传输只确认、不重放事件或结算，过期命令返回最新权威状态。
- 客户端实现退避重连和未确认命令发件箱；重连后用服务端完整投影收敛状态。房主离开不结束或转移房间，凭原 token 重连恢复管理权。
- 增加协议版本拒绝、匿名运行指标和 TLS/WSS 公网部署边界；补充恢复、重复投递、过期 revision、房主恢复和版本不兼容测试。
