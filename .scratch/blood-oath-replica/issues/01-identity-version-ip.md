# 确认游戏身份、版本与 IP 边界

Type: research
Status: resolved

问题：确认“鲜血盟约”的正式名称、出版方、目标版本/扩展、玩家人数、胜利条件和计划平台；列出可合法使用的资料，并定义未授权时必须原创或占位的内容边界。

输出：一页版本基线、术语表、资料来源清单、授权决策和非目标清单。任何规则歧义都要标成待确认，而不是猜测实现。

完成条件：后续票据可引用唯一版本；产品 brief 明确“规则兼容”与“内容复制”的边界。

## Answer

- 已确认项目交付边界：浏览器网页客户端、多人联机、用户本地启动权威服务端并通过内网穿透分发；首轮以桌面浏览器验证，同时保留手机（含 iPhone）和平板的响应式/触控兼容路径，不交付客户端安装包。
- 用户已提供规则来源并明确目标为 `Blood Bound`：基础角色集合为红、蓝两家族各 1–9 号身份，支持 6–12 人；未提及扩展。出版方、发行印次和授权仍未核验，不能从名称或第三方条目推断。
- 授权仍未知，按未授权处理：只能使用原创/占位名称、文案、图形、地图和规则数据，不能复制官方规则书原文、卡牌文案、Logo、插画、版图、扫描件或包装。
- 详见 [研究笔记](../research-01-identity-version-ip.md)。如需消除出版方、印次或授权的不确定性，请补充出版方/发行方官方产品页、官方规则书或版权页、盒底条码与版本信息，或权利方授权/地区发行页中的任一可核验入口。
