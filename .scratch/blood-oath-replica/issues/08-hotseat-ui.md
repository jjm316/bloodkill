# 交付浏览器多人对局界面

Type: prototype
Blocked by: 05, 06, 07

问题：设计并实现浏览器中的建局/加入房间、版图/区域、玩家面板、手牌/能力、行动选择、确认/撤销、响应窗口、日志、计分和回放视图。所有状态均来自本地权威服务端；首轮优先桌面布局，同时定义手机（含 iPhone）与平板的响应式/触控降级。

输出：低保真流程原型、可操作桌面布局、窄屏降级方案、规则解释入口、键盘/触屏交互规范。

完成条件：6-12 人在不同浏览器中不读开发者控制台即可完成一局；所有按钮状态来自服务端确认的引擎合法行动；非法行动有原因；审判官秘密诅咒与家族公开信息按玩家视角过滤；回放和当前局共享投影组件。
