# 终局胜负弹窗

Status: ready-for-agent
Implementation: complete

## 已明确的需求

- 对局结束时显示胜负弹窗，明确说明谁赢、谁输。
- 展示每个人的昵称、身份牌等级、真实所属家族；家族使用对应颜色。2026-10-11 澄清：无需额外展示 ID。
- 两个家族与审判者分开呈现，审判者不归入任一家族。
- 胜者的个人信息后有明显胜利标识。
- 分别适配手机与电脑横屏，保证全员信息可阅读。
- 所有面向玩家的文案使用简体中文。

## 已核实的约束

- 术语与身份依据根 CONTEXT.md：玫瑰家族、野兽家族、独立的审判者。
- 颜色沿用现有真实阵营色：玫红、兽蓝、紫色。
- 审判者被捕获独赢遵循 ADR 0007；真诅咒覆盖家族胜利及终局真假公开遵循 ADR 0014。
- 当前 Board.tsx 的 ResultBanner 是页面内横幅，尚非自动弹出的终局弹窗。
- 改造前公开 PlayerView 不包含所有人的真实身份。
- 已核实：当前服务端结束态投影仍隐藏其他人的身份；需增加仅终局公开的真实身份数据，不能从徽记、亮牌颜色或备忘标记推断。
- ranking 的 score=1 表示胜、score=0 表示负；place 是排序序号，不能用于显示身份牌等级。被捕获不直接决定输赢。
- 审判者等级为特殊身份 fleur-cross，应中文显示「审判者」，不编造数字等级。
- 偶数局没有审判者；旧回放可能存在平局或缺失身份数据。

## 已确认的展示决策

- 个人信息为昵称＋身份牌等级。
- 玫瑰家族、野兽家族、审判者分别分组。
- 2026-10-11 确认采用 A：电脑两家族并排，审判者下方独立横条；手机纵向排列。
- 终局自动弹出，顶部展示获胜方和本人胜负。胜者金色星标＋「胜利」，败者明确标「失败」。
- 无审判者时隐藏该分组；关闭后可通过「查看结果」再次打开。刷新或重连后可查看完整结算。
- 个人胜负直接使用引擎结算；旁观者不显示本人胜负。旧回放平局显示「平局」，缺失身份明确提示，不猜测。
- 2026-10-11 补充：超出玩家信息框的昵称保持单行，使用跑马灯读取完整文本；名单与座位卡保持对齐，短昵称静止。悬停暂停，键盘聚焦后可手动横向滚动，减少动态效果偏好下保留单行手动阅读。
- 键盘可聚焦并滚动结算名单；Tab 在名单、溢出昵称与关闭按钮之间循环。

## 布局草图

- A 阵营对照：电脑两家族并排，审判者独占下方横条；手机三组纵向排列。建议方案。
- B 分组名册：统一纵向名单，用阵营标题分段，电脑与手机保持阅读顺序。
- C 阵营分页：默认显示胜者名单，其他阵营切换查看；省空间但不能同时看到全员。
- 原型可模拟玫瑰胜、野兽胜、审判者独赢，以及 6/7/11 人和电脑宽屏/手机竖屏/手机横屏。
- 草图里的昵称、等级、诅咒归属和具体捕获原因都是虚构演示数据，不用于验证规则。
